# 能力映射

完整的订单来了 App 页面、MCP 工具、109 个已确认 action 和未接入边界见：[订单来了 App 与 MCP 能力映射](./订单来了App与MCP能力映射.md)。本文件保留酒店经营域的快速索引；页面存在不等于 MCP 接口可用。

英文基线的 `hotel-vibe-coder` 已并入中文包的 `hotel-digital-operations`，只提供当前工作区内的本地网页、页面规格和内容数据交付；外部部署与预订引擎实际接入仍按详细映射的边界处理。

| PMS 报表与财务 | `report.*`、`finance.*`、`wallet.*`：营业、住宿、集团、销售、会员、流水、收银、AR、发票和钱包 |

餐饮桌台、菜品套餐、娱乐场地、营销店铺/活动、SCRM、短信、硬件打印和 OTA 运营等 App 页面，当前清单没有完整专用 MCP action；具体边界见 [订单来了 App 与 MCP 能力映射](./订单来了App与MCP能力映射.md)。

## 需协作或人工提供

- 竞品价格、STR、Demand360、市场需求指数
- OTA 账单、佣金、评价和渠道后台数据
- 银行对账、AP、完整总账和税务申报
- 专业 CRM、RFP、媒体投放和社交平台数据
- 工程工单、预防性维护和失物招领系统
- 官网、Booking Engine、代码托管和部署

## 处理原则

技能可以基于 PMS 数据给出经营判断，但不能把“建议”写成“已经完成的外部系统操作”。
App 有页面但当前 MCP 清单没有完整 action 的功能，按人工页面或用户提供文件处理，并明确写出“当前未接入”。
