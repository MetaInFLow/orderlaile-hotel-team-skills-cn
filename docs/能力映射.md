# 能力映射

## 已支持

| 领域 | 订单来了 CLI |
|---|---|
| 订单与住宿 | 查询、详情、汇总、编辑、取消、排房、入住、退房、NoShow |
| 房价库存 | 查询、批量改价、批量改库存、价格码启停、日志 |
| PMS 报表 | 营业额、房费、间夜、入住率、OCC、ADR、RevPAR |
| 客户会员 | 客户、会员卡、优惠券、积分、客户标签 |
| 员工权限 | 员工、角色、权限、班次、交接班 |
| 餐饮商超 | 餐厅、桌位、菜品、套餐、库存、出入库 |
| 门店设置 | 收款方式、打印、通知、门店资料和图片 |
| 营销活动 | 连住优惠、抽奖、分销 |

## 需协作或人工提供

- 竞品价格、STR、Demand360、市场需求指数
- OTA 账单、佣金、评价和渠道后台数据
- 银行对账、AP、完整总账和税务申报
- 专业 CRM、RFP、媒体投放和社交平台数据
- 工程工单、预防性维护和失物招领系统
- 官网、Booking Engine、代码托管和部署

## 处理原则

技能可以基于 PMS 数据给出经营判断，但不能把“建议”写成“已经完成的外部系统操作”。
