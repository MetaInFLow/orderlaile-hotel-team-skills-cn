# 飞书 / 钉钉协作模板

飞书 CLI 和钉钉 CLI 只承载协作内容，不承载 PMS 事实数据。

## 经营日报文档

建议字段：

| 字段 | 说明 |
|---|---|
| 日期 | `yyyy-MM-dd` |
| 门店 | 真实门店名称 |
| 数据来源 | 订单来了 CLI / 用户提供文件 |
| 核心指标 | 入住率、ADR、RevPAR、房费、营业额 |
| 今日重点 | 到店、离店、VIP、团体、异常 |
| 风险 | 风险、影响、负责人、截止日期 |
| 决策 | 待总经理确认的事项 |

## 风险台账

建议字段：

```text
风险编号、门店、风险类别、风险描述、证据、影响、严重度、
负责人、截止日期、缓解措施、状态、最后更新时间
```

## 改价 / 改库存确认单

建议字段：

```text
确认编号、门店、日期、房型、价格码、旧值、新值、变更原因、
预计影响、用户确认原文、执行时间、执行结果、复核结果
```

## 任务台账

建议字段：

```text
任务、来源、门店、负责人、截止日期、优先级、状态、阻塞原因、
关联订单 / 房型 / 活动、完成证据
```

## 消息规则

- 只发送结论、影响、负责人和截止日期。
- 不在群消息中发送 token、完整证件号、银行卡号或完整手机号。
- 写操作确认必须保留用户明确确认原文。
- 失败结果按门店或目标逐项列出，不能只报一个总数。
