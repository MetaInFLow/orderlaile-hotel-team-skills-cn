# 订单来了 CLI 查询问题模板

订单来了 CLI 的 `query` 必须是完整中文自然语言问题，不能只传模糊关键词。

## 查询模板

```text
查询【门店名称】在【yyyy-MM-dd】至【yyyy-MM-dd】的【业务对象】，
按【房型 / 价格码 / 状态 / 客户 / 员工】筛选，
返回【需要的字段】并说明统计口径。
```

## 改价模板

```text
请查询【门店名称】在【yyyy-MM-dd】至【yyyy-MM-dd】、
【房型】、【价格码】的当前房价。
如果目标唯一，生成把价格从当前值调整为【目标价格】的变更预览；
不要执行，等待我确认。
```

## 改库存模板

```text
请查询【门店名称】在【yyyy-MM-dd】至【yyyy-MM-dd】、
【房型】的当前库存。
如果目标唯一，生成把库存调整为【目标库存】的逐日变更预览；
不要执行，等待我确认。
```

## 日报模板

```text
查询【门店名称】在【yyyy-MM-dd】的入住率、ADR、RevPAR、房费、
营业额、到店、离店、在住、取消、NoShow、房态异常和收银异常，
按日报口径汇总，并列出需要负责人处理的事项。
```

## 节假日模板

```text
查询【节假日名称】官方放假首日和末日。
最终 PMS 范围必须使用：放假首日前一天至放假末日。
先返回明确的 yyyy-MM-dd 日期范围，未确认前不要写入。
```

## 失败处理

查询异常、写入失败、异步部分失败时，停止当前流程。只能重新查询最终状态、展示失败明细和说明原因，不能自动重试。
